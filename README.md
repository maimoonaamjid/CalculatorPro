# Calculator Pro (JavaFX)

A modern scientific calculator built using JavaFX with a clean interface and smooth animations.

## Features

- Dark and Light mode toggle
- Scientific functions (sin, cos, tan, log, ln)
- Expression evaluation (+ − × ÷)
- Animated buttons
- Clean and simple UI

## Technologies Used

- Java
- JavaFX
- NetBeans IDE
- JDK 17+

## How to Run

1. Open the project in NetBeans
2. Ensure JavaFX is configured
3. Run `CalculatorPro.java`
